Connect this computer to your phone

Folio uses a small helper on your computer to keep your devices in sync. There is no hosted Folio sync service yet.

First time? Start the computer helper
  1. On this computer, open a terminal in the Folio project folder.
  2. Run npm run sync:computer and leave it running.
  3. Choose Connect this computer above. Allow the browser's request to connect to the helper.
  4. Copy the pairing code that appears. On your phone, open Devices, paste it, and choose Pair this device.

Use the same Wi-Fi on your computer and phone. The debug Android app supports this local connection. Sync works while the computer helper is running; downloaded stories still work without it. A release app or syncing across different networks needs an HTTPS server.

Your browser cannot start the helper itself. A packaged desktop installer is not included in this development build.

Already have a pairing code?
Advanced: use my own sync server

Use this if you already run an HTTPS Folio sync server. Enter its address here; your phone will receive it in the pairing code.

Your phone is one code away.

On your phone, open Folio → Devices, paste this code, and choose Pair this device.

This code grants access to your library. Share it only with your own devices.

Once paired, sync runs every minute and when you choose Sync now. Open a saved title in the Folio reader once to share its page list, then select Keep offline on your phone. Page images are downloaded on the phone, separately from encrypted library sync.
