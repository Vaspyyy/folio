ƒ. WELCOME TO FOLIO

    How do I start the computer helper?

    On your computer, in the Folio project folder, run:

    npm ci
npm run sync:computer

    In the extension's library, open Your devices and choose Connect this computer. Folio finds the connection address for you. Copy its pairing code to Devices on your phone.

    Keep the helper running and use the same Wi-Fi on your computer and phone. This local connection works with the debug Android app. For a release build or syncing across different networks, use your own HTTPS sync server under Advanced.

    You can use Folio locally without setting up a relay.
